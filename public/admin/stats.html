Daily numbers table

Unique visitors are counted per browser without cookies: the browser only remembers the date it was last counted. Someone using two devices, a private window, or who clears their browser data is counted again, so treat these as close estimates. People who switch on Do Not Track or Global Privacy Control in their browser aren't counted, and search engines are filtered out, so real use is a little higher than shown. Assistant uses are counted on the server each time a case is sent; the case text is never stored.
